# Challenge4

Problem Statement:
Create a C program called LOOPLAB to analyse daily expenses. Repeatedly read expense amounts until the user enters 0. For each positive
amount, classify it using the rules below, update counts and totals, and finally display a summary. Use loops, conditional statements, arithmetic
operators, and variables. Do not use arrays, functions, or strings.

Algorithm:
1. Start
2. Initialize all counts and totals to 0.
3. Read the expense amount repeatedly until the user enters 0.
4. If the expense is below ₹100, update the Small count and total; if below ₹500, update the Medium count and total.
5. Otherwise, update the Large count and total.
6. Display the counts and totals of all three categories.
7. Stop
